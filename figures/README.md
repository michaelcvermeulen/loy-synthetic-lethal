# Thesis Figures (`figures/`)

This directory contains the figure-generation scripts, figure numbering registers, captions, and the **87 thesis PDFs** included in the finalized PhD thesis:

- **Chapter 1 (`figures/chapter1/`):** 4 main figures (`Fig 1.1–1.4`)
  - [`chapter1_figure_numbering.md`](chapter1/chapter1_figure_numbering.md) — Official figure numbering register for Chapter 1.
  - [`chapter1/exports/`](chapter1/exports/) — `Fig 1.1` (`ch01_main_synthetic_lethality_concept_draft.pdf`), `Fig 1.2` (`ch01_main_xy_genes_regions_draft.pdf`), `Fig 1.3` (`ch03_main_intro_tcga_prevalence_hazard_paired.pdf`), and `Fig 1.4` (`ch03_main_intro_tcga_loy_arm_losses.pdf`).
- **Chapter 3 (`figures/chapter3/`):** 15 main figures (`Fig 3.1–3.15`) and 44 supplementary figures (`Supp Fig 3.1–3.44`) = **59 thesis PDFs**
  - [`chapter3_figure_numbering.md`](chapter3/chapter3_figure_numbering.md) — Official sequential first-mention numbering register for Chapter 3.
  - [`Chapter3_figure_captions.md`](chapter3/Chapter3_figure_captions.md) — Complete figure titles and panel-by-panel captions.
  - [`chapter3/code/`](chapter3/code/) — R and Python plotting scripts for the 59 Chapter 3 thesis figures.
  - [`chapter3/exports/`](chapter3/exports/) — Final vector PDF exports for `Fig 3.1–3.15` and `Supp Fig 3.1–3.44`.
- **Chapter 4 (`figures/chapter4/`):** 8 main figures (`Fig 4.1–4.8`) and 16 supplementary figures (`Supp Fig 4.1–4.16`) = **24 thesis PDFs**
  - [`chapter4_figure_numbering.md`](chapter4/chapter4_figure_numbering.md) — Official sequential first-mention numbering register for Chapter 4.
  - [`chapter4/code/`](chapter4/code/) — R and Python plotting scripts for the 24 Chapter 4 thesis figures.
  - [`chapter4/exports/`](chapter4/exports/) — Final vector PDF exports for `Fig 4.1–4.8` and `Supp Fig 4.1–4.16`.

> **Note:** Non-thesis exploratory figures and draft scripts are stored locally in `_local_non_thesis/` (excluded from Git via `.gitignore`).

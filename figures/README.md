# Thesis Figure-Generation Code (`figures/`)

This directory contains the R and Python plotting scripts that generate the main and supplementary figures in Chapters 3 and 4 of the PhD thesis:

- **Chapter 3 (`figures/chapter3/code/`):** R and Python scripts for the 15 main figures (`Fig 3.1–3.15`) and 44 supplementary figures (`Supp Fig 3.1–3.44`) in Chapter 3 (*Generation and Molecular Characterization of Isogenic Loss of the Y Chromosome Cancer Models*).
- **Chapter 4 (`figures/chapter4/code/`):** R and Python scripts for the 8 main figures (`Fig 4.1–4.8`) and 16 supplementary figures (`Supp Fig 4.1–4.16`) in Chapter 4 (*Functional Genomics and Synthetic Lethal Vulnerabilities in Loss of the Y Chromosome Cancer Models*).

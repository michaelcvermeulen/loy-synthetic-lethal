# TF analysis methods and interpretation

The extension reuses the existing six-sample edgeR quasi-likelihood analysis. Positive effects indicate LOY versus CTRL. The requested DA subsets use BH FDR <0.05 and |log2FC| >1; the effect-size cutoff is a descriptive subset of zero-null tests. The established independent-replicate model is retained. Passage-adjusted results are a sensitivity analysis; technical-batch assignments have not been supplied and passage labels have not been relabeled as batch.

Known-motif enrichment uses HOMER 5.1 `findMotifsGenome.pl -size given -nomotif -useOldBg`, with the JASPAR2024 CORE vertebrate nonredundant set (879 motifs). Gained and lost subsets are analyzed separately. Backgrounds are sampled without replacement from tested non-DA consensus regions (FDR >=0.20), matching 5-percentage-point GC bins and average-logCPM deciles. The control-to-target ratio is constant across strata within each comparison, up to 10:1; matching accounting is retained. HOMER additionally weights sequences for nucleotide composition, so its effective background total can differ from the number supplied. Native sequence/group-weight files are retained.

For HOMER input, PFMs are converted to positive probabilities with 0.25 added per nucleotide, a 0.001 probability floor, and column renormalization. MOODS provides natural-log-odds score thresholds at site P=5e-5 against uniform base frequencies. The converted motifs and thresholds are saved. Reported fold enrichment is target motif fraction divided by the HOMER background motif fraction. P-values are reconstructed from HOMER's natural-log P column because its displayed P column is rounded to powers of ten. BH correction is recomputed across all motifs and both directions within each model arm. Bar plots show one representative motif per mapped group and retain motif-level statistics; they do not assign a new family-level FDR.

chromVAR 1.32.0 uses the original integer fragment counts for all six samples and 84,506 tested non-Y/PAR peak sequences without N bases. Motifs are matched using motifmatchr 1.32.0 at site P=5e-5. GC/accessibility-matched background sampling uses 50 iterations and seed 20260908. Both bias-corrected deviations and deviation z-scores are exported. Z-scores are standardized against chromVAR's background distribution, not standardized across the six samples. Limma compares sample-level scores under independent and passage-adjusted designs with separate BH correction per analysis arm. Welch t-tests are provided as sensitivity results. A reported effect is a z-score difference, not a log2 fold change.

Vierstra v2.1beta metadata provide motif-group assignments. Exact JASPAR ID/version mappings are preferred; unique accession mappings to other versions are explicitly labeled. Ambiguous or absent mappings remain separate. Group annotations for chromVAR use the union of member motif-positive peaks. All member identities and unresolved mappings are retained; group signals cannot identify a unique paralog.

All three methods start from the same JASPAR2024 matrices and nominal motif-site P threshold. Their native pseudocount, background-frequency, scoring, and enrichment models differ, so identical site calls are not assumed. Method agreement is assessed by motif ID and effect direction, with all method-specific results retained.

TOBIAS 0.17.5 runs ATACorrect, ScoreBigwig, and BINDetect. Eligible unshifted proper-pair BAMs are sampled by read name to approximately equal non-Y depth per replicate, then merged by condition with read-group provenance. The target is 13,595,165 fragments per replicate; actual counts and seeds are retained. Neither reads nor replicates are added by pooling. ATACorrect applies its internal +4/-5 Tn5 correction once, excludes chrY/mitochondrial chromosomes, uses the blacklist, and retains default signal normalization. ScoreBigwig uses its default footprint scoring parameters. BINDetect compares LOY first with CTRL second on the common tested consensus, using the same JASPAR motif set and site P=5e-5. Native bound-site thresholding and score normalization are retained. Pooled-site P-values and any added BH correction are not biological-replicate differential tests; native highlighted flags are not FDR calls.

The exported hg38 FASTA is normalized to Unix line endings and its complete set of 84,510 tested peak sequences is compared with an independent BSgenome getSeq export. BAM/reference chromosome lengths are checked. Every HOMER-extracted sequence must exactly match this independent sequence reference before the run is marked complete. Earlier outputs from package-relocation and FASTA-line-ending failures are retained in explicitly invalid directories and excluded from summaries.

TF transcript statistics come from the user-selected HT1080 combined-batch DESeq2 `~ batch + treatment` result without refitting. Unique exact-symbol joins and case-insensitive candidate joins are distinguished; ambiguous and absent symbols remain unresolved. Dimer motifs retain links to each constituent TF. Comparisons are group-level because direct ATAC/RNA sample matching is not established. Transcript direction need not agree with motif accessibility or footprint score direction. Neither motif enrichment nor footprinting proves TF binding experimentally.

TF transcript annotations retain Y-linked genes and record RNA chromosome/Y-linkage flags; this does not change the original primary ATAC/RNA gene-overlap universe. Present genes with nonfinite RNA statistics are retained and flagged separately from unmapped symbols. A selected sex-chromosome TF coverage table records that ZFY RNA is decreased in the source result but no motif is named ZFY in this JASPAR set. Zfx is a case-insensitive candidate label match to ZFX, and SRY has a motif model but no row in the selected RNA result. Missing motif labels or RNA rows are not tests of protein expression or specific occupancy.

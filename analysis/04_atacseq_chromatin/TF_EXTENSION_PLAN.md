# TF analysis extension

Requested 2026-09-08. Existing results are retained; extension outputs go to motifs/TF_extension/.

1. DA: retain edgeR quasi-likelihood, LOY minus CTRL. Export the requested FDR <0.05 and |log2FC| >1 subsets with MA/volcano plots. This is an effect-size subset of the zero-null test, not a minimum-effect hypothesis test. Batch adjustment requires actual technical-batch metadata. The current six-sample metadata contains passage 11/12/21; this is not automatically technical batch. Independent-replicate and passage-adjusted analyses already exist and remain explicitly labeled.
2. Known motifs: HOMER findMotifsGenome.pl -size given with JASPAR2024 CORE vertebrate nonredundant motifs. Analyze gained and lost peaks separately. Select backgrounds only from tested consensus peaks with FDR >=0.20, matched on GC and average accessibility, and report matching accounting, target/background proportions, fold enrichment, P-values, and multiple-testing correction. Optional de novo discovery is deferred.
3. chromVAR: six separate raw integer count columns, tested non-Y/PAR peak universe, fixed seed, GC/accessibility-matched background sampling. Export bias-corrected deviations and deviation z-scores. Limma group comparisons and requested Welch t-tests have BH correction. Retain passage adjustment as a sensitivity analysis until batch is confirmed. Z-score differences are not log2 fold changes.
4. Motif families: use Vierstra v2.1beta metadata to map exact JASPAR IDs where possible. Unique accession matches across versions are explicitly marked; ambiguous/unmapped IDs remain separate. chromVAR archetype annotations are unions of member motif-positive peaks, not minimum member P-values. Preserve all member identities for RNA interpretation.
5. Footprinting: TOBIAS ATACorrect -> ScoreBigwig -> BINDetect, same hg38 reference/consensus and blacklist, with internal Tn5 correction applied once. Pool eligible unshifted BAMs by condition for footprint visualization; retain replicate provenance and assess matched-depth sensitivity. Pooled BINDetect statistics are not replicate-aware differential tests. Footprints are predicted occupancy; no claim of experimentally demonstrated TF binding.
6. Concordance: join motif IDs/families across HOMER, chromVAR, and TOBIAS with explicit sign conventions, and append the selected HT1080 batch + treatment RNA statistics. RNA samples are not established as directly matched to ATAC; use group effects. TF transcript changes need not agree with motif accessibility or binding predictions.
7. Figures: DA MA/volcano, gained/lost enrichment, per-sample motif/family z-score heatmaps, footprint score comparison and aggregate QC, cross-method concordance, and TF RNA effects. Display FDR and retain discordant findings.

Sources: [HOMER](https://homer.ucsd.edu/homer/motif/findMotifsGenome.html), [chromVAR](https://greenleaflab.github.io/chromVAR/), [TOBIAS](https://github.com/loosolab/TOBIAS), [JASPAR2024](https://jaspar2024.elixir.no/downloads/), [Vierstra mapping](https://resources.altius.org/~jvierstra/projects/motif-clustering-v2.1beta/).

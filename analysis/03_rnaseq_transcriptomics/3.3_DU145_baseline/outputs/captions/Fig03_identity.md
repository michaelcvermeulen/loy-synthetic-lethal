**Fig03_identity**

Spearman correlation of library log2(TPM + 1) with default DepMap 26Q1 profiles over the 8,000 most variable shared protein-coding genes (hash-verified release files). Top ten matches plus DU145 and LNCaP are shown. AR, KLK3, KLK2, FOLH1 and HOXB13 are shown with KRT/VIM context. This supports DU145 identity from RNA; STR profiling was not performed here.

# Focused review of reannotate_v105

Reviewed as the source of methods for the September reanalysis. Original notebooks and outputs were not modified. The confirmed population history supplied by the user changes the interpretation of all sample-level inference.

1. **High priority: serial passages do not provide independent population-generation replication.** The original paired passage design in [analysis_HT1080.Rmd](../../reannotate_v105/analysis_HT1080.Rmd:39) cannot distinguish LOY effects from the histories of these two established populations. August and May also resample the same populations. The new primary tables therefore report matched effects, observed variation and temporal repeatability without gene-level population significance claims. This is a design limitation, not something a different model can repair with these samples.

2. **High priority: chromosome-arm concordance is overridden by an explicit list.** [analysis_HT1080_extended.Rmd:1616](../../reannotate_v105/analysis_HT1080_extended.Rmd:1616) declares `arm_force_cooccur`, then ORs membership with the numerical concordance rule. Consequently chr22p, chr6p, chr8q and chr13p are marked concordant even when the rule fails. Those colors/labels cannot be interpreted as results of the stated criterion. The new analysis contains no override and does not integrate unmatched DNA specimens.

3. **High priority: chromosome midpoints are used as centromeres.** [analysis_HT1080_extended.Rmd:1594](../../reannotate_v105/analysis_HT1080_extended.Rmd:1594) assigns p/q by the median of the chromosome's observed coordinate range. This can place genes on the wrong arm and invalidate arm-level summaries, especially for acrocentric chromosomes. The new annotation uses real GRCh38 cytobands; checks confirm BRCA2 and RB1 are on chr13q. WGS coordinates require their own assembly-compatible mapping.

4. **High priority: the compensation index is not total RNA compensation.** [analysis_HT1080_extended.Rmd:994](../../reannotate_v105/analysis_HT1080_extended.Rmd:994) uses `X_logFC + Y_logFC`, with zero interpreted as perfect compensation. Opposite log fold changes balance multiplicative ratios, not baseline-weighted X+Y abundance. The replacement reports individual genes and `(X_LOY + Y_LOY)/(X_CTRL + Y_CTRL)` from consistently normalized, length-adjusted abundance proxies, without a functional-compensation claim.

5. **Medium priority: VIPER combinatorial errors are caught and can leave the stage absent.** [viper_HT1080.Rmd:490](../../reannotate_v105/viper_HT1080.Rmd:490) passes `nn` to `msviperCombinatorial`; the installed API uses `level`. The error handler returns NULL, so the expected results can disappear while the notebook continues. In addition, the synergy export at [line 511](../../reannotate_v105/viper_HT1080.Rmd:511) reads ordinary enrichment P values rather than the synergy-specific result. The new core uses CollecTRI ULM and explicitly records combinatorial VIPER as unrun.

6. **Medium priority: annotation changes when the analysis is rerun.** [analysis_HT1080.Rmd:156](../../reannotate_v105/analysis_HT1080.Rmd:156) selects the newest available EnsDb; the directory name does not fix that resource. Counts were generated from GENCODE v49. The new analysis annotates exact versioned counting IDs against that same frozen GTF and records SHA256 hashes. Symbol-requiring analyses use deterministic representatives without consulting differential statistics; main tables preserve every locus.

The unambiguous-symbol/chromosome compatibility check against the old August export covers 18,193 genes and yields an effect correlation of approximately 0.979. This does not validate the old significance, chromosome-arm or compensation claims. The old export lacks exact gene IDs, so ambiguous symbol joins are omitted. See `outputs/tables/legacy_August_effect_comparison.csv` and the new report for the full comparison and its limits.

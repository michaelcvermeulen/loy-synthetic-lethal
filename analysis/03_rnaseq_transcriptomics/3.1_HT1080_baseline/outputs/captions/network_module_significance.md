# All-module annotation significance

**Functional-annotation significance for all lower- and higher-RNA network modules in HT1080 LOY.** a, All 24 lower-RNA modules. b, All 18 higher-RNA modules. Module identifiers and their order match the MCODE atlas; row labels are descriptive module summaries. Each row uses the previously selected top GO biological-process or Reactome annotation with at least two overlapping genes. Open circles show raw one-sided hypergeometric P values and filled diamonds show the corresponding Benjamini–Hochberg-adjusted q values, plotted as −log10 values on a common scale. Connecting lines show the change after adjustment; the vertical dashed line marks 0.05. Numeric columns report both probabilities. BH correction spans all 260,526 module–term tests (42 modules × 6,203 terms), using 14,564 expressed STRING-mapped genes as background. The original values were reused without new testing or a smaller correction family. All modules are retained, including D20 with q = 0.657. Exact tested terms and full-precision probabilities are supplied in the source CSV. These exploratory annotation statistics describe functional coherence; they do not test module-level RNA change, protein interaction or causal LOY effects in independently generated populations.

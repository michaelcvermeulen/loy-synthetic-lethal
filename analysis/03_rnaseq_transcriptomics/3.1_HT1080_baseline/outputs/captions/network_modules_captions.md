## HT1080_LOY_network_modules_DOWN

**Protein-association modules among genes with decreased RNA in established HT1080 LOY populations.** The eight highest-scoring of 24 modules are displayed (66 genes). Candidates satisfy the existing absolute combined log2-expression difference ≥ 0.5, period-direction agreement and six leave-one-match-out direction checks. Combined effects equally weight August 2025 and May 2026. a, Human STRING v12.0 associations with scores ≥ 0.7 were clustered using a local Python implementation of MCODE (degree cutoff 2; node-score cutoff 0.2; k-core 2; haircut enabled; fluff disabled; maximum depth 100). Colors distinguish modules; node sizes scale with absolute combined RNA differences. Solid edges also have STRING physical-network scores ≥ 0.7; dashed edges denote other STRING associations. Only within-module edges are shown; layout distances carry no biological meaning. b, Top GO biological-process/Reactome annotations and representative genes. Annotation BH adjustment covers all 260,526 module–term tests across both directions, using 14,564 expressed STRING-mapped genes as background. These exploratory annotations share knowledge with the network resource. The complete atlas and candidate-background sensitivity are supplied separately. Six timing matches repeatedly sample the same established populations; RNA changes and reference associations do not establish altered protein abundance, binding or pathway activity.

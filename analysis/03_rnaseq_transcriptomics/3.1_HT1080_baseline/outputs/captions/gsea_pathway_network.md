# GSEA pathway networks

**Gene-set similarity networks for the HT1080 LOY transcriptional ranking.** a, Higher-RNA enrichment (32 sets); b, lower-RNA enrichment (776 sets). Every combined fgsea result with original global Benjamini–Hochberg q < 0.05 is retained from the 23,696 eligible MSigDB 2026.1.Hs H and C1–C9 tests. Nodes represent gene sets, and node area is 4 + 4 × [−log10(q)] square points. Connections require at least three shared combined-ranking leading-edge genes and Jaccard similarity (intersection divided by union) ≥ 0.25; line width increases with similarity. Only within-direction relationships are displayed. Weighted Louvain communities (resolution 1, seed 42) define the groups; selected groups have descriptive labels and colours, while other groups are grey. Community colours are local to each direction. Source cell-type or phenotype labels describe the originating signatures, not inferred HT1080 cell identity. Shapes show global q < 0.05 and agreement with the combined NES direction in August, May, both periods or neither period (combined only). These categories describe threshold support, not a statistical test of differences between periods. All 808 sets have concordant NES signs in both periods. The 19 higher-RNA and 489 lower-RNA sets without qualifying leading-edge edges occupy separate strips. Component packing, spring layouts and isolate ordering are display choices; distances have no biological meaning. The companion full-membership figure uses the same nodes, colours and coordinates, but computes edges from complete set membership intersected with the 25,461-gene ranking universe. The offline interactive report displays exact names, statistics, memberships and shared genes, and offers Jaccard thresholds 0.20, 0.25, 0.35 and 0.50. No enrichment tests or BH adjustments were rerun. These are exploratory patterns in repeated samples of the same established populations; estimated-correlation CAMERA has no combined global-BH discoveries. Neither gene-set similarity nor source chromatin signatures demonstrate protein interaction or measured HT1080 chromatin activity.

Method background: [EnrichmentMap similarity definitions](https://enrichmentmap.readthedocs.io/en/latest/Parameters.html) and [GSEA leading-edge definition](https://enrichmentmap.readthedocs.io/en/docs-2.2/AdditionalFeatures.html). This extension uses a local NetworkX implementation of an enrichment map.

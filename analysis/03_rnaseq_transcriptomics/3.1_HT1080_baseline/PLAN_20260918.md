# HT1080 RNA-seq programme analysis: agreed plan

Author interview, 18 September 2026. This extension is stored in `outputs/programme_analysis_v1/`; earlier analyses remain available and are not overwritten. The folder name is implementation provenance, not thesis narrative.

## Question and interpretation

Which transcriptional programmes change in Y-depleted HT1080 cells? Lead with changes that have consistent directions across August 2025 and May 2026; examine period-dependent responses separately. These are serial samples of one established population per condition, not independently generated models. Model-based tests assume independent residuals conditional on the design.

## Agreed decisions

1. Main DE: batch + condition on the 12 core libraries, retaining the existing 25,526 expressed autosomal/non-PAR X genes and TMM exposures. Preserve the previous passage-aware fit as sensitivity.
2. Directionally consistent genes: main FDR <0.05, absolute estimated log2FC >=1, and matching directions in August and May, also agreeing with the main effect. Keep period-specific estimates; direction agreement does not imply stable magnitude. This is a zero-effect test plus effect-size filter, not TREAT.
3. Period response: batch * condition model, with explicit August, May and May-minus-August condition-effect contrasts. The interaction FDR, not significance in one period alone, defines evidence of effect heterogeneity. Retain the passage-aware interaction as sensitivity.
4. Primary programme scope: Hallmark, Reactome and GO Biological Process equally. Use all tested, uniquely mapped symbols rather than the filtered DE list for ranked enrichment. Implementation choice: signed moderated t statistics; BH across all three selected collections separately for each contrast. Other MSigDB collections are follow-up resources.
5. Directionally consistent programmes: overall enrichment FDR <0.05 and matching NES directions in both periods. Flag FDR <0.05 support in both periods. Preserve leading-edge genes per period and their overlap.
6. Group significant pathways by shared leading-edge genes: Jaccard >=0.25 and >=3 shared genes, separate positive/negative networks, weighted Louvain seed 42. Retain full-membership and threshold sensitivities. Assign biological labels from member terms and genes, not inherited community IDs.
7. Rebuild complementary STRING/MCODE modules from the new directionally consistent gene set, split by effect direction. Retain score thresholds and MCODE settings from the earlier implementation; document mapping coverage. Protein association is not measured coexpression.
8. Infer TF activity from signed target-expression patterns using the frozen CollecTRI resource. Prioritise consistent directions across periods and overlap with leading programme genes. TF expression is separate evidence; inferred activity is not measured binding.
9. August-only sgCTRL-minus-parental DE: three libraries per group, unpaired because passage matching is unknown. Separate expression filter and TMM fit for this six-library comparison; report tested overlap with primary DE. No May extrapolation or attribution specifically to nucleofection. Use contextual pathway/TF analyses of this contrast.
10. Y-linked and PAR expression: separate dosage-focused branch; exclude from primary programme/TF background. Preserve the PAR-inclusive volcano as a companion analysis.
11. RNA–ATAC integration: combine expression, linked accessibility and TF-motif evidence around programme themes. Show all themes in an overview, then investigate 3–5 supported themes. Distinguish proximity from supported enhancer links and motifs from binding. Check population, passage and reference compatibility before integration.
12. Supplementary results: comprehensive pathway/TF tables, model/period sensitivity, broader signatures, all network modules and detailed supporting figures. No fixed figure limit.

## Planned Results order

Design/QC/global expression → overall and directionally consistent genes → programme enrichment and themes → STRING modules → inferred regulators → period-dependent responses → parental context → programme-focused RNA–ATAC integration. Y/PAR dosage remains separate.

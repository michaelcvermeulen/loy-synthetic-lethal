# Regional Y atlas adoption

The author approved integrating all three completed realignment atlases into Chapter 3 draft 2 on 28 October 2026, with sex-chromosome dosage and expected PAR retention in the captions.

The current figures are draft 2 Figs 3.4–3.6 (historical central Figs 3.10, 3.12 and 3.14). Full source, interpretation and reproduction details are in [the figure source record](../../../figures/chapter3/source_data/regional_y_atlases_ypar_20261028/README.md).

`prepare.py` archived the pre-adoption state and froze approved inputs. `adopt.py` verified equivalence to the previews, adopted PDF/SVG/PNG files, updated content-addressed inline previews, synchronised captions and changed only the corresponding Results values. These migration scripts are historical execution records; use the canonical renderer to rebuild figures. `adopted_figures.json` records hashes, numbering and medians; `captions.json` records the synchronised caption bodies.

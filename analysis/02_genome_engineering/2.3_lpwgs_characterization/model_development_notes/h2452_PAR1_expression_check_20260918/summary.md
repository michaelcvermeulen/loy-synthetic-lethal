# H2452 public PAR1 expression check

No consistent PAR1-wide decrease relative to the other 21 mesothelioma models in DepMap Public 26Q1. Of the 10 assayed PAR1 genes with reference median expression >=1 TPM, seven are above the reference median in H2452 and three below. ZBED1 is lower (0.607-fold); SLC25A6 and ASMTL are modestly below (0.842- and 0.897-fold). CD99 is higher (1.281-fold). SHOX and ASMT have zero expression in H2452 and zero reference medians; they are not informative for a regional decrease.

This is a descriptive baseline cross-model comparison, not a before/after expression analysis or a differential-expression test. It uses public RNA-seq, not the excluded in-house H2452 RT-qPCR. The reference cohort is lineage-matched but not matched for ploidy or Y state. Released PAR expression is not allele-resolved and does not distinguish X-derived and Y-derived transcripts; PAR genes have homologous X/Y copies. Thus these RNA values cannot establish whether the Y-derived PAR contribution is reduced.

Ensembl PAR documentation: https://mart.ensembl.org/info/genome/genebuild/human_PARS.html

Source and comparisons: H2452_vs_mesothelioma.csv, study_models_PAR1_TPM.csv, PAR1_default_expression_profiles.csv. Profile metadata and hashes are retained alongside these files.
